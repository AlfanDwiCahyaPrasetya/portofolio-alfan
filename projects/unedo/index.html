01 // PROJECT OVERVIEW

UNEDO: Welder Competency Certification & Job Recruitment Ecosystem

UNEDO is a specialized web platform designed to connect certified welders, training institutions, and industrial employers across manufacturing, construction, and oil & gas sectors. Developed collaboratively by Team Zenith at CV FlyHigh Sinergi Indonesia, the system digitizes certification enrollment, verified work experience tracking, peer networking, and recruitment workflows through a scalable RESTful API backend.

Background

Certified welding professionals require standardized verification of welding positions (such as 1F–6G, SMAW, GMAW, and GTAW) and valid competency credentials, yet existing certification and recruitment records are often fragmented across manual administrative processes.

Motivation

To bridge the gap between skilled welders and industrial recruiters, our team built a centralized digital platform featuring secure JWT authentication, automated certification quota management, structured experience portfolios, and data-driven administrative reporting.

Key Platform Features

01

Token-Based Authentication & Security

Implemented registration, login, token refresh, and session tracking using Laravel 12, JWT, Laravel Sanctum, and bcrypt password hashing.

02

Certification & Experience Portfolio

Enables welders to enroll in certification programs with quota validation, upload digital certificates, and log verified project histories.

03

Recruitment & Professional Network

Provides multi-criteria job filtering, CV applications, company reviews, welder-to-welder connections, community posts, and bookmarks.

04

Admin Dashboard & ANP Support

Delivers real-time applicant statistics and certification analytics to support strategic evaluation using the Analytic Network Process (ANP).

02 // DATABASE DESIGN & RESTFUL API

Entity Relationship Diagram (ERD) & API Architecture

As the Backend Developer on Team Zenith, I designed the relational database schema and developed the RESTful API endpoints powering user authentication, profile management, welder work experience, certification programs, job vacancies, and administrative dashboards.

  • Users Domain: Manages users, user_sertifikat, pengalaman, koneksi, lamaran, daftar_obrolan, pesan, and status_pengguna.
  • Admin & Certification Domain: Handles admin, sertifikasi, and loker with automated quota tracking and status controls.
  • Community & Auth Domain: Powers postingan, postingan_comment, postingan_like, and autentikasi session token records.

Sample RESTful API Endpoints

Method Endpoint Function Description
POST /api/auth/register Register a new welder account with welding levels and skills
POST /api/auth/Login Authenticate user credentials and issue a signed JWT token
POST /api/auth/logout Invalidate the active user session and revoke access token
POST /api/auth/refresh Refresh an expired JWT token to maintain session continuity
GET /api/auth/me Retrieve the currently authenticated user's profile details
GET /api/auth/user/1 Retrieve public profile data of a specific user by ID
PUT /api/profile Update authenticated user's personal and professional profile
POST /api/profile/update Delete or reset user profile record data
DEL /api/profile/photo Remove the authenticated user's uploaded profile photo
POST /api/pengalaman/upload Upload a new welder work experience record via Form-Data
POST /api/pengalaman/update/1 Update an existing welder work experience entry by ID
DEL /api/pengalaman/delete/1 Delete a specific welder work experience entry by ID
GET /api/pengalaman/delete/1 Retrieve welder work experience details for verification
